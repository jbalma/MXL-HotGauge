#End to End
This is the directory from which you can run end to end HotGauge simulations. 
You can run the script by copying the config template, filling out the fields 
at the top of the config file, and then running: `python run_HotGauge.py --config {your config}`

For help filling out the fields at the top of config template, please refe to
the **HotGauge_use_instructions** document in the HotGauge root, which provides an overview
of the inputs and outputs to the different tools in the HotGauge toolchain.
